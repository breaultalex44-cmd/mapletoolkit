# 🍁 Maple Toolkit

> **Canada Hub & Calculators**

A lightweight, mobile-optimized web application built for Canadians, featuring live feeds, financial calculators, and utility tools[cite: 1].

🌐 **Live Site:** [https://breaultalex44-cmd.github.io/mapletoolkit/](https://breaultalex44-cmd.github.io/mapletoolkit/)

## 📱 Works on Mobile Screens
Designed with a responsive mobile-first interface, native CSS variables, automatic dark mode support (`prefers-color-scheme`), and fluid safe-area padding for modern mobile displays[cite: 1].
