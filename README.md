# 🍁 Maple Toolkit

> **Canada Hub & Calculators**

A lightweight, high-performance, and mobile-optimized web application built specifically for Canadians, featuring multi-unit conversion utilities, sales tax engines, mortgage amortization schedules, income tax estimators, TFSA growth modeling, and real-time Canadian news and financial feeds.

🌐 **Live Site:** [https://breaultalex44-cmd.github.io/mapletoolkit/](https://breaultalex44-cmd.github.io/mapletoolkit/)

---

## ✨ Key Features & Architecture

* **Canadian Financial Calculators:** Comprehensive estimation tools including Canadian income tax brackets, sales tax (GST/HST/PST) breakdowns across provinces, mortgage payments with semi-annual compounding, and tax-free savings account (TFSA) compound growth projections.


* **Live Canada Hub & Intelligence Feeds:** Integrated live feeds categorized by Major News, Diplomacy, Economics, Provincial & Local News, Elections, and Active Conflicts.


* **Responsive Mobile-First UI:** Built with native CSS variables, automatic dark mode support (`prefers-color-scheme`), and fluid safe-area padding for modern mobile and desktop displays.

## 🛠️ Technology Stack

* **Frontend:** Single-file HTML5, CSS3, and JavaScript architecture optimized for lightning-fast mobile loading speeds.


* **Storage:** LocalStorage persistence for user preferences, dark mode states, and calculator configurations.


* **Data Integration:** Live outbound RSS/query feeds linked directly to Google News (Canada), Yahoo Finance (^GSPTSE, CAD=X), and official federal statistics sources.
